# Identidad Camposol

`camposol-original.jpg` es una copia exacta del archivo proporcionado por el usuario, `logo-camposol-peru-1.jpg`. Se utiliza intacto en la placa del robot y en los controles. No se redibujaron las letras ni el emblema.

La mascota incorpora referencias de riego tecnificado: carcasa de filtro, tubos de PE, codos, uniones, acoples de latón, manómetro y volante de válvula. El manómetro y el volante son elementos decorativos y no representan mediciones ni controles físicos de Dream.
